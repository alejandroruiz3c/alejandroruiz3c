Built with FastAPI, React, PostgreSQL, Qdrant and object storage. Public source snapshot available; in development, with production and complete user-journey verification still pending.

- **[SALES OS](https://github.com/alejandroruiz3c/ai-sales-system)** — an agentic, multi-tenant sales platform **in development**. The current implementation reaches the LLM and prompt foundation (F2); the broader sales workflow remains a roadmap.
- **TurbineH Onboarding** — verified email onboarding, guided AI conversations and report generation. Security and release verification are in progress.

## Engineering approach

Tenant isolation, explicit product status, reproducible development environments,
source-linked evidence and tests that exercise real system boundaries.

Repository documentation distinguishes implemented functionality from roadmap
items and local verification from live deployment validation.
